Classes and Objects

Terms

  • Class - defines a template for a type of thing, like a cookie cutter
  • Object - individual instance of a class, like a cookie
  • Property - variable that is specific to an object, a way to customize, like cookie decorations
  • Method - function that is specific to an object, something an object can do, like bake

More Terms

  • constructor - special method that is called when an object is created, typically properties are initialized here, like cutting and decorating a cookie
  • this - special keyword for referencing the individual object, like “I’m going to decorate this cookie with sprinkles”
