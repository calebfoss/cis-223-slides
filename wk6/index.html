Iteration

Repetition + change

Danger!

Mistakes when setting up a loop can result in infinite repetition, causing the program to get stuck forever. Save your work before creating a loop!

Iteration Ingredients

  1. initialization - create a variable to keep track of change
  2. test - condition that will be true until it's time to stop repeating
  3. update - change made every time the code repeats, typically assigning a new value to the initialized variable3

while


// Initialization
let count = 0;

// Test
while(count < 100) {
  console.log(count);

  // Update
  count++;
}

for


            // Initialization; Test; Update
            for(let count = 0; count < 100; count++) {
              console.log(count);
            }
